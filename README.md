# IoT-Motion-Detector-with-Email-Alert

## Description
This project detects motion and sends email alerts.

## Components Used
- ESP8266 NodeMCU
- PIR Sensor (HC-SR501)
- LED +220ohm resistor
- WiFi Router

## Working
PIR sensor detects motion.
ESP8266 triggers IFTTT webhook.
Email alert is sent to user.

## Output
User receives email when motion is detected.
